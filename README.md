# Onefile

**One file. A whole whiteboard.**

An infinite canvas that lives entirely in a single HTML file. No install, no account, no server. Just open it in a browser.

## Features
- Infinite canvas — pan and zoom freely
- Add text and images
- Group objects together
- Undo / redo
- Save your canvas — produces a new standalone `.html` file with everything embedded
- View-only mode for presenting
- Keyboard shortcuts for everything

## How to use
1. Download `index.html`
2. Open it in any browser
3. Start adding text and images
4. Press **Ctrl+S** (or **⌘S** on Mac) to save your canvas as a new file

## Keyboard shortcuts
| Key | Action |
|-----|--------|
| `T` | Add text |
| `I` | Add image |
| `Space` + drag | Pan canvas |
| `Ctrl/⌘ + S` | Save canvas |
| `Ctrl/⌘ + Z` | Undo |
| `Ctrl/⌘ + G` | Group selected |
| `Delete` | Delete selected |
| `1` | Fit to content |
