Shortcuts

Mac: use ⌘ for Ctrl, ⌥ for Alt

  • T – Add text
  • I – Add image
  • M – Add mindmap node
  • Space + drag – Pan canvas
  • Shift + click – Multi-select
  • Shift + drag – Marquee select
  • Ctrl/⌘ + A – Select all
  • Ctrl/⌘ + C – Copy
  • Ctrl/⌘ + X – Cut
  • Ctrl/⌘ + V – Paste
  • Ctrl/⌘ + Z – Undo
  • Ctrl/⌘ + Y or Shift+Z – Redo
  • Ctrl/⌘ + G – Group
  • Ctrl/⌘ + Alt/⌥ + G – Ungroup
  • Ctrl/⌘ + S – Save canvas
  • Delete – Delete selected
  • Shift + Resize – Maintain aspect ratio
  • +/- – Zoom in/out
  • 1 – Fit to content
  • Double-click text to edit
  • Shift + Enter – Line break in text
  • Drag empty canvas to pan
